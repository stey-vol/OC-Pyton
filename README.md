# OC-Pyton
Сбор информации об операционной системе и компьютере используя Python
В ходе работы была написана программа на языке Python для получения основных сведений о компьютере и используемой операционной системе.
Для этого были подключены стандартные модули Python: json, platform, os, socket, sys. 
Полученные сведения были собраны в один словарь info. После этого программа создала файл my_script.json и записала в него собранные данные в формате JSON. Для сохранения русских символов использовался параметр ensure_ascii=False, а параметр indent=4 сделал содержимое файла более удобным для просмотра. 
Собираемые параметры: 
Программа получает следующие сведения: 
1. Операционная система — определяется с помощью platform.system().
2. Версия операционной системы — определяется с помощью platform.version().
3. Выпуск операционной системы — определяется функцией platform.release().
4. Архитектура компьютера — определяется с помощью platform.machine().
5. Процессор — информация о процессоре получается с помощью platform.processor().
6. Количество ядер процессора — определяется с помощью os.cpu_count().
7. Имя компьютера — определяется функцией socket.gethostname().
8. Версия Python — сохраняется значение sys.version.
9. Путь к исполняемому файлу Python — определяется через sys.executable.
10. Имя текущего пользователя — получается с помощью os.getlogin().
Результат: после запуска программы в папке проекта создается файл my_script.json, в котором все полученные сведения сохраняются в структурированном виде. Это позволяет открыть файл отдельно и посмотреть характеристики компьютера и среды Python.
Библиотека json используется для работы с данными в формате JSON. В программе она нужна для сохранения собранной информации в отдельный файл. info — словарь со всей собранной информацией; file — открытый файл, в который записываются данные; ensure_ascii=False — позволяет сохранять русские буквы без преобразования их в специальные коды; indent=4 — добавляет отступы, благодаря чему JSON-файл становится более удобным для чтения.
Библиотека platform предназначена для получения информации об операционной системе и аппаратной части компьютера.
Библиотека os позволяет взаимодействовать с операционной системой.
Модуль socket используется для работы с сетевыми функциями компьютера.
Модуль sys предоставляет доступ к некоторым параметрам и функциям, связанным непосредственно с Python.
